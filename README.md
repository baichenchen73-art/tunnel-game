## 遊戲介紹

手繪紙張風格的橫向卷軸冒險遊戲。

你提著一盞燈，從地道的落點醒來。前方一直有個提著同樣燈籠的身影，總是走在你前面，怎麼追都追不上。跟著那道光往深處走，穿過倒映的湖、倒過來的小鎮、燈芯礦坑、結冰的湖面、停擺的鐘樓、紙燈籠祭典的夜空、被墨水淹沒的書庫，一直到暴風雪的山路。每到一個地方，就會想起一點被忘掉的事。

![遊戲畫面：結冰的湖面、停擺的鐘樓、祭典的夜空、墨水書庫](docs/screens.jpg)

## 特色

- **每一章一種新玩法**：衝刺或二段跳、潛水、重力翻轉、燈鏈擺盪、冰面滑行與破冰、機關齒輪、乘著風飛行、划墨水船，還有暴風雪山路上的「時間凍結與融化」——敲亮搜救燈，燈光照到的冰才會融開，要趁燈熄前快點通過
- **每一章都有專屬的怪物和 Boss**：怕光的熄燈者、慢半拍模仿你的映照者、要先破解機關的停擺大鐘、跟著鼓點才打得動的祭鼓、在書頁間出劍的書靈劍仙、要引進燈光裡才打得動的雪怪……
- **燈火技能**：焰火、寒霜、暖光三個派系，學會之後每打倒一個 Boss 就能讓一招進化，也能用光屑強化
- **同行的夥伴**：書庫裡會遇到戴著狐狸面具的小燈精，牠會跟著你一起冒險、自己出招，還能和你一起放合擊技
- **寒冷與取暖**：暴風雪的山路上離開燈火越久越冷，凍僵了會受傷；靠近存檔燈籠、點亮的搜救燈或搜救隊留下的炭火堆就能取暖
- **支線與收集**：每章都有等著你幫忙的角色、記憶碎片，以及可以用地圖傳送的燈籠存檔點；各章也有能慢慢回血的地方，像書庫裡溫著的硯台、山路上的炭火堆
- **電腦與手機都能玩**：電腦用鍵盤（按鍵可以自訂），手機橫拿用虛擬搖桿和觸控按鈕

## 操作（電腦版預設）

| 動作 | 按鍵 |
| --- | --- |
| 移動 | A / D 或 ← → |
| 跳躍（按住跳更高） | 空白鍵 或 ↑ |
| 攻擊 | J 或 滑鼠左鍵 |
| 衝刺 | K 或 滑鼠右鍵 |
| 對話／進入 | E |
| 技能／技能頁面 | L ／ N |
| 地圖 | M |
| 設定 | Esc |

各章學到的新能力（點燈、燈鏈、破冰等），遊戲裡都會提示怎麼按。

手機版：橫拿手機，按住畫面左半邊下方拖動就是搖桿（左右走、往下推破冰）；右下是攻擊、跳躍、衝刺、技能鍵；燈油鍵靠近門或角色時會變成「進入／對話」。按鍵大小和透明度可以在「設定」調整。
